Database Backup

Run an on-demand backup of taxops.db using SQLite's online backup API — safe while the app is live. Backups are stored in the configured backup directory with a UTC timestamp filename. Old backups beyond the 30-day retention window are pruned automatically each run.

Manual Backup

Triggers the same backup routine as the nightly Task Scheduler job. Each run creates one new taxops_backup_<timestamp>.sqlite file and removes files older than 30 days.

Configuration

  • TAXOPS_BACKUP_DIR — backup destination (default: C:\TaxOps\backups\)
  • TAXOPS_BACKUP_RETENTION_DAYS — days to keep (default: 30)
  • TAXOPS_BACKUP_ALERT_WEBHOOK — optional Slack webhook for failure alerts
  • TAXOPS_BACKUP_ERROR_LOG — path to error log (default: inside backup dir)

Nightly schedule: Task Scheduler runs scripts/nightly_backup_db.py at 2:10 AM. See scripts/register-nightly-backup-task.ps1 to register the task.

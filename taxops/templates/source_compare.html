Database vs source files

The manual office log is usually one chronological workbook with YR marking the tax season for each intake row — the same semantics as CSV import (log numbers may come from LOG yyyy matching each row's year when present). This screen compares the selected tax year returns in TaxOps against log rows whose YR equals that year; rows for other seasons are still matched separately (see counters below). Amber highlights are value deltas vs the database.

Welcome to TaxOps

Here is where everything lives:

Main

  • Dashboard All clients and returns — search, filter, and track status.
  • Bookkeeping Monthly bookkeeping queue and client periods.
  • New Intake Walk-in worksheet — start a new client or re-intake a returning one.
  • Return detail Documents, notes, missing items, prep workspace, and status history.

Daily menu

  • Pickup Queue Returns ready for client pickup at the counter.
  • E-File Queue Returns ready to transmit — build batches from here.
  • Work Orders Non-return walk-in requests and billing checklists.
  • Now Serving Lobby take-a-number — call next, transfer windows, keep the line moving (header button too).
  • Extension Queue Extension requests waiting to be batched and filed.
  • Email Inbox Unassigned client emails — attach attachments to the right return.
  • Email Campaigns Office mass-email templates and sends (when you have permission).
  • Docs not scanned Returns where intake scan was skipped — finish scanning later.
  • Receipt Queue OCR receipt review before QuickBooks export.
  • Spouses / Dep. Review Admin checks for spouse and dependent data that need a human look.

Occasional menu

  • Compliance Tracker Sales tax / city licenses and filing status by client.
  • Filing Periods Period board for compliance filings across months.
  • Payments Fee collection and balances by return.
  • Review Documents flagged by extraction that need confirmation.
  • Batches & Import E-file / extension batches, CSV import, source compare, import audit.
  • Admin tools Staff accounts, announcements, sender rules, audit log, backups, email health, season rollover, merge clients.
